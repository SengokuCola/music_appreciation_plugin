# 音乐赏析

让麦麦赏析网易云歌曲，支持歌名、歌手和歌曲链接。

## 使用

1. 将插件放入 MaiBot 的 `plugins/music_appreciation_plugin` 目录并加载。
2. 在 WebUI → 插件管理 → 音乐赏析 → 配置，填写模型 API 密钥，保存。默认使用百炼 `qwen3-omni-flash`，也可填写支持音频输入的接口地址和模型。
3. 对麦麦说：“听一下周杰伦的晴天并赏析”，或发送网易云歌曲链接并请它赏析。

会员歌曲可在配置中填写网易云 `MUSIC_U` 或完整 Cookie，发送 `/网易云状态` 检查登录。密钥和 Cookie 只填在配置里。

找错歌曲版本时请直接提供歌曲链接。无法获取音频的歌曲不能赏析；音频超过配置上限时只赏析截取的部分。
